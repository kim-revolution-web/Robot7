1) 네 메모 내용 요약 정리
왜 venv를 쓰는가

Ubuntu/WSL에서 apt(시스템 패키지) 로 설치한 파이썬/라이브러리와
pip(파이썬 패키지) 로 설치한 라이브러리가 섞이면

업데이트 꼬임, 의존성 충돌, OS 패키지 깨짐 같은 문제가 생길 수 있음

그래서 시스템 영역 설치가 제한되는 경우가 있고,

해결책으로 venv를 만들어 그 안에서 pip로 PyQt6 설치하면 안전함.

pip / apt / venv 한 줄 정리

pip: 파이썬 라이브러리 설치 도구 (PyQt6, opencv 등)

apt: 우분투 OS 프로그램/패키지 설치 도구 (git, python3-venv, qttools 등)

venv: 프로젝트마다 pip 설치 공간을 분리하는 가상환경

Designer vs PyQt6

Designer: .ui 파일을 만드는 개발 도구

PyQt6: .ui를 로드해서 실제로 GUI를 실행하는 런타임(엔진)

.ui 연결 방식 핵심

.ui에서 objectName이 Speed면 로드 후 self.Speed로 자동 접근 가능

uic.loadUi(BASE_DIR + "main.ui", self)로 UI 파일을 로드

버튼 objectName을 키로 해서 self.mapping으로 로봇 명령 문자열로 변환해서 큐로 보냄

(F) DummyRobot 테스트에서 핵심(“GUI만” 단독 검증)

GUI는 큐에 넣기만 하니까, 더미 로봇이 큐를 꺼내서 값을 바꿔줘야 화면이 바뀜

def poll_queue():
    while not robot.command_queue.empty():
        msg = robot.command_queue.get()
        cmd = msg.get("cmd", "").upper()
        if cmd in ["AUTO", "MANUAL"]:
            robot.control_mode = cmd
        else:
            robot.apply_cmd(cmd)


이걸 QTimer로 계속 돌림:

t = QTimer()
t.setInterval(20)
t.timeout.connect(poll_queue)
t.start()
